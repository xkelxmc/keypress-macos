# Contributing

Bug reports and feature requests are welcome — open an
[issue](https://github.com/xkelxmc/keypress-macos/issues).

## Before you open a pull request

Keypress is a paid product on the Mac App Store, and its source is published
under the [PolyForm Strict License 1.0.0](./LICENSE) so that anyone can audit
what an app with Input Monitoring permission does. That license does not by
itself let the maintainer ship contributed code commercially, so contributions
need the terms below.

Please open an issue first. Unsolicited pull requests may be closed without
review.
