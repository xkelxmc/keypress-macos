# Contributing

Bug reports and feature requests are welcome — open an
[issue](https://github.com/xkelxmc/keypress-macos/issues).

## Before you open a pull request

Show KeyPress is a paid product on the Mac App Store, and its source is
published under the [PolyForm Strict License 1.0.0](./LICENSE) so that anyone
can audit what an app with Input Monitoring permission does. That license does
not by itself let the maintainer ship contributed code commercially, so
contributions need the terms below.

For the sole purpose of preparing and submitting a contribution, the license
lets you do what that requires — change the code, build and test it, fork this
repository and push to your fork — see "Additional Permissions" in
[LICENSE](./LICENSE). Everything else the license withholds stays withheld.

Please open an issue first. Unsolicited pull requests may be closed without
review.
